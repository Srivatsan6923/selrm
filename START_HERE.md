# START HERE: ROLE B (training)

You run one of four parallel Claude Code sessions that together execute the
full v10 paper. This package is self-contained.

## Setup (15 minutes)
1. Put this folder in the team repo on branch `role-b` (the lead
   creates the repo; if it does not exist yet, start locally and push later).
2. Add a shortcut to the shared Drive folder `selrm/` in your My Drive.
3. Open the folder in Claude Code and paste **Prompt 1** from `PROMPTS.md`.

## Your part afterwards
- COMPUTE REQUEST appears -> open the named notebook on your GPU and press
  Run all (or add the named secret), then send Prompt 3.
- New session or lost context -> Prompt 2.
- Daily 15-minute sync: bring numbers from `summary_*.json` only.

## What you own
Every trained model in the paper. 225 rows in `docs/RUN_MATRIX_B.csv` (32 are P0).
Details: `ROLE.md`. Shared rules: `CLAUDE.md`. Contracts: `docs/INTERFACES.md`.
Schedule: `docs/TEAM_PLAN.md`.

## Already built and tested in this package
`selrm/schema.py`, `selrm/prompts.py`, `selrm/metrics.py`, `selrm/smoke.py`,
`scripts/make_smoke.py`, `scripts/validate_shortcuts.py`,
`tests/test_foundation.py`. `data/smoke_v2` (generated by the script) has
held-out rules and held-out templates, so every role can build against the
final record format from the first hour.

## Limits to know
- Colab cannot be driven remotely: you start each GPU notebook yourself.
- Nothing from smoke data may be reported.
- The human lead submits the paper; Claude Code does not.
