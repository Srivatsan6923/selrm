## Section 3.1, "Edits and invariants"

**3.1-12.** "The engine edits the mentions of one input ... and keeps an edit only if executing the

**3.1-13.** "A flip changes a mention that A_j counts so that c_j changes, no other criterion does,

  That is why no proposal is ever rejected for an indecisive flip (C-2).

**3.1-14.** "A near-miss ... is numeric (a counted value moves toward the threshold without

- "Boundary" is a value exactly at a **strict** threshold. At an inclusive threshold that value is
  a flip (item 8).
- Proposed wording: *"a value exactly at a strict threshold is its own kind; at an inclusive
  threshold the same value is a flip"*.

**3.1-15.** "or concerns applicability (the concept and value of the flip are reported in a mention
that A_j does not count: another subject, absent status, or a time outside A_j)." *Partly.*
- **Subject:** a person the predicate does not count, at the flip's time.
- **Time:** a past or resolved mention, or a delabelled allergy. For a measurement, an older dated
  value crosses the threshold while the current value stays on the default side.
- **Negation:** A_j does count this mention, which is the patient's, current, with status absent
  (status is not part of A_j). The criterion fails because nothing counted is present.
- Proposed wording: *"... reported in a mention that A_j does not count (another subject, a time
  outside A_j), or in a counted mention whose status is absent"*.
- A negation near-miss on a criterion that counts past or family mentions differs from its flip in
  status and also in time or subject:
  670 of
  2180 negation near-misses in the test and
  development sets. This happens because the flip may be a past or a relative's mention, while the
  denial is the patient's, now.

- It is not matched in size to a flip: it reorders every line.
- Proposed wording: *"re-renders the same state in another line order and header, with measured
