## Limits
- Labels are the rule code's points on the released (or edited) entity dictionary, relative to the score text shown. Edited notes are not real patients.
- Value edits change one number; other statements of the note that depend on it (a second laboratory value, a described appearance) are not changed. The lexicon of words for values and the fidelity filter remove some such notes, not all.
- Sentence edits come mostly from a few scores, because the notes of the other scores mention every item (table above).
- A scorer that reads values but ignores subject, status and time solves every value edit; selectivity is tested by the sentence edits only.
